# Quick Formula Sheet

| Topic | Formula |
|---|---|
| Mobility | $F = 3(n−1) − 2j_p − j_h$ |
| Grashof | $s + l < p + q$ |
| Vector sum (2) | $R = \sqrt{A^2+B^2−2AB\cosθ}$ |
| Components | $R_x = ΣA_x,\; R_y = ΣA_y$ |
| Quick-return | $Q = (180°+β)/(180°−β)$ |
| In-line slider-crank | $L_2 = \text{stroke}/2,\; L_3 > 4L_2$ |
| Transmission angle | $40° < γ < 140°$ |
| v from ω | $v = rω,\; ω = n·2π/60$ |
| Relative velocity | $ω_{AB} = v_{B/A}/AB$ |
| Acceleration | $a^t = rα,\; a^n = ω^2r = v^2/r$ |
| Cam speed | $ω = 1\,\text{rev}/ΣT$ |
| Constant-A cam | $a = ±4H/T^2$ |
| Harmonic cam | $a_{max} = π^2H/(2T^2)$ |
| Cycloidal cam | $a_{max} = 2πH/T^2$ |
| Gear geometry | $p = πd/N,\; P_d = N/d,\; d_b = d\cosφ$ |
| Gear ratio | $VR = N_2/N_1,\; TV = ΠVR$ |
| Pitch-line speed | $v_t = πdn/12$ (fpm) |
| Belt length | $L = 2C + π(D_2+D_1)/2 + (D_2−D_1)^2/(4C)$ |
| Sprocket | $D = p/\sin(180°/N)$ |
| Screw | $ΔR = pΔθ,\; v = pω$ |
| Equilibrium | $ΣF_x = ΣF_y = ΣM = 0$ |
