# Things to Double-Check With Your Instructor

1. **Slide 170 (four-bar α₃/α₄):** printed formulas differ from book eq. 7.23/7.24 (likely typos). This site uses the book version.
2. **Slides 93–94 (four-bar design):** handwritten 133.3 rpm does not match the stated 2.15 s cycle (≈ 27.9 rpm).
3. **Slide 242 (chain length):** last term needs C in pitches to be dimensionally correct.
4. **Slide 219:** face-width rule $F = 12/P_d$ is a single value; the book may give a range (unverified).
5. **Image-only slides:** many figures (Chapters 4–7) are summarized as method + results; widgets here are redrawn from the slide method.
