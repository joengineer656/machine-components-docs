Mechanism Design (Synthesis)

هنا نعكس المسألة: نعرف الحركة المطلوبة ونريد أطوال الأذرع. الفكرة الأساسية: زمن الشوط الأمامي لا يساوي زمن الرجوع.

In-line slider-crank (Q = 1)​

L2=Δ(R4)max2stroke=2L2L_2 = \frac{Δ(R_4)_{max}}{2} \qquad \text{stroke} = 2L_2L2​=2Δ(R4​)max​​stroke=2L2​

Smooth acceleration needs L3≫L2L_3 \gg L_2L3​≫L2​; rule of thumb L3>4L2L_3 > 4L_2L3​>4L2​.

Slide design: stroke 1.25 in, 0.2 s out and 0.2 s back → L2=0.625L_2 = 0.625L2​=0.625 in, L3>2.5L_3 > 2.5L3​>2.5 in.

Quick-return action​

Q=advance timereturn time≥1Q = \frac{\text{advance time}}{\text{return time}} \ge 1Q=return timeadvance time​≥1 Q=180°+β180°−ββ=180°Q−1Q+1Q = \frac{180° + β}{180° − β} \qquad β = 180°\frac{Q-1}{Q+1}Q=180°−β180°+β​β=180°Q+1Q−1​

Crank speed (rpm) = 60 / cycle time in seconds.

β = 20.0° — advance sweeps 200.0° (yellow), return 160.0° (red). Checks: Q 1.25 → 20.0°, Q 1.75 → 49.1°.
